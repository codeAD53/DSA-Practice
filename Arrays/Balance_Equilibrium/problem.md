# Balance Equilibrium

## Problem
Given an array of integers, find an equilibrium index: an index where the sum of all elements to its left equals the sum of all elements to its right. The element at the index is excluded from both sums. If multiple indices qualify, report the first one.

## Input
The first value is the array size `N`, followed by `N` integers.

## Output
Print the zero-based index of the first equilibrium position, or report that no equilibrium exists.
