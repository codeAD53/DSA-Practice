# Seating Plan

## Problem Statement

Given a seat number, find out the seat number facing you and seat type facing you, i.e; WS, MS, or AS
where 
- `WS`: Window Seat
- `MS`: Middle Seat
- `AS`: Aisle Seat

The seating arrangement is shown below:
![Seating Arrangement](seating_plan.jpg)

## Input Format
Take single integer N denoting the seat-number as a input.

## Constraints:
`1 <= N <= 108`

## Output Format
print the facing seat-number and the seat-type, separated by a single space in a new line.

## Example


```text
Input:
3
Output:
AS 10
