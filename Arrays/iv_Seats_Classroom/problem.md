# Seats in a Classroom / Theater

## Problem Statement

Find all the possible ways in which n people can occupy r number of seats in a classroom/theater

## Input Format
User gives two inputs(number of people and seats).

## Constraints
1 <= N, R <= 1000

## Output Format
If the number is people are more than number of seats then print "Cannot adjust n people on r seats" otherwise print all possible arrangements.

## Example

Input
```text
5 9
```
Output
```text
15120
