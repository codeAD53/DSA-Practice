# Colors of Balls

## Problem Statement

In a market, a shopkeeper is selling different colors of balls. He sells N number of different colors of balls . The task is to find the color (odd) of the balls which is present odd number of times in the bunch of balls.

**Note:**

If there is more than one color which is odd in number, then the first color in the array which is present odd number of times is displayed. The colors of the balls can all be either upper case or lower case in the array. If all the inputs are even in number, display the message “All balls are even”.

## Input Format

Input N 

Input N colors in array

## Constraints

1 <= N <= 1000

## Output Format
Print First Odd Color Name in uppercase otherwise print All balls are even

Input
```
10
r b B R g g R y b Y
```

Output
```
R
