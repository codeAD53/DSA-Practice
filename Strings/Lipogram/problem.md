# Lipogram Check

## Problem
Given a sentence and a letter, determine whether the sentence is a lipogram with respect to that letter. It is a lipogram if the specified letter does not occur anywhere in the sentence. Letter matching is case-insensitive.

## Input
The first line contains the sentence. The next token contains the letter to check.

## Output
Print `Lipogram` if the letter is absent; otherwise, print `There is no Lipogram`.
