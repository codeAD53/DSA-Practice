# Pangrammatic Lipogram

## Problem
Given an English sentence, determine whether exactly one letter of the English alphabet is missing. If exactly one letter is absent, identify that letter. Ignore spaces and punctuation, and treat uppercase and lowercase letters as equivalent.

## Input
A line of text containing the sentence.

## Output
If exactly one letter is missing, print that the sentence is pangrammatic and print the missing letter. Otherwise, print that it is not pangrammatic.
