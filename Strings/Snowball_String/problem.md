# Snowball String

## Problem
Given a sentence ending in a period (`.`) or question mark (`?`), determine whether it is a snowball string. A sentence is a snowball string when each word after the first has exactly one more character than the word before it. Words are separated by whitespace; ignore the terminating punctuation.

## Input
A non-empty line of text ending in `.` or `?`.

## Output
Print whether the sentence is a snowball string. Report invalid input if the line is empty or has a different terminating character.
