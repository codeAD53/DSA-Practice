# Convert 12-Hour Time to 24-Hour Time

## Problem
Convert a time from 12-hour format with an `AM` or `PM` suffix to 24-hour format. The input time includes hours, minutes, and seconds.

## Input
A time in the form `HH:MM:SSAM` or `HH:MM:SSPM`, where the hour is from `01` to `12`.

## Output
Print the converted time in `HH:MM:SS` format, using a two-digit hour from `00` to `23`. Print an error message for an invalid input format or time.
